# sa7ab - مصنع سحاب للملابس الجاهزة

منظومة إدارة وتشغيل المصنع، الكوادر، خطوط الإنتاج، بونص الانتظام المحاسبي، والمزامنة السحابية.

## المميزات الرئيسية
- **منظومة بونص الانتظام (أسبوعي وشهري)** وفق القواعد المعتمدة للمصنع.
- **إدارة شؤون الموظفين والعمال**، تسجيل الخصومات والمكافآت والملاحظات الإدارية مع الربط المباشر بمسير الرواتب.
- **محطة الحضور والانصراف والباركود / QR السريع**.
- **مسير الرواتب المحاسبي الشامل** وحساب المستحقات وصافي الأجر.
- **إدارة الفواتير والعملاء ودفتر الخزينة النقدية**.
- **نظام المزامنة الذاتية والعمل أوفلاين** مع دعم Supabase Cloud Sync.

## التشغيل محلياً (Run Locally)
```bash
npm install
npm run dev
```

المنفذ الافتراضي للتشغيل: `48200`
